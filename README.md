# Opening Trainer

A desktop chess app (Electron) that teaches openings move by move, explains why each move is played, and uses spaced repetition so the lines stick. Stockfish 19 is built in.

## Run it

```
npm install
npm start
```

`npm start` bundles the UI (esbuild) and opens the app. Requires Node 18+.

The **Opening Trainer** desktop shortcut runs `launch.vbs`, which does the same without a console window. Its icon is `assets/icon.ico`, generated by `npm run theme`.

## What's in it

**Repertoire (home).** Separate tabs for *Playing White* and *Playing Black*. Every line can be trained from either side (except the Fried Liver, which is a White-only weapon). Each line shows its status: New, Due, Next in Xd, or Mastered.

**Openings included** (about 10–12 moves deep, every move explained):

| Caro-Kann | Italian Game |
|---|---|
| Advance – Short System | Giuoco Pianissimo (c3 + d3) |
| Classical 4...Bf5 | Giuoco Piano c3 + d4 main line |
| Karpov 4...Nd7 with 5.Ng5 | Evans Gambit |
| Exchange | Two Knights – 4.Ng5 d5 5.exd5 Na5 |
| Panov–Botvinnik | Fried Liver Attack (White only) |
| Two Knights | Two Knights – modern 4.d3 |
| Fantasy 3.f3 | |

Each opening also has an **Overview & plans** page: pawn structures, plans for each side, and traps.

**Learn.** The trainer shows your move (arrow and explanation), you play it, and the opponent replies with its own explanation. If you try a different move, Stockfish compares your move with the book move from your side's point of view.

**Drill (spaced repetition).** You play the line from memory. *Hint* (key `H`) highlights the piece, then shows the move. At the end you grade yourself (Again / Hard / Good / Easy); a grade is suggested from your mistakes. Intervals follow an Anki/SM-2 style schedule: 10 minutes for Again, then 1d → 3d → growing. Trouble spots are remembered per line.

**Explore & Study.**
- A free board with a move tree, including side variations (Promote / Delete). Navigate with ← → Home End; press F to flip.
- Stockfish analysis: top 3 lines plus an eval bar. Click a line to play it.
- **Book** tab: repertoire moves from the current position, with explanations, and whether the last move was book.
- **Notes** tab: write notes on any position. Notes are tied to the position, so they also appear during drills when you reach it.
- **Saved studies**: save and reopen whole move trees.
- Play against the engine from any position (Easy, Club, Strong, Full).
- Load / copy FEN or PGN.
- **Save line to repertoire…**: turns the moves on the board into your own Learn/Drill line.

**My Lines.** Edit or delete your custom lines. You can add them to Caro-Kann or Italian, or create a new opening. The data file holds all progress, notes, studies and custom lines (`%APPDATA%/opening-trainer/chess-trainer-data.json`); back it up by copying it.

## Piece set

The default set is **Norse**, inspired by the 12th-century Lewis chessmen:
- Ivory against red-stained ivory.
- Seated kings with swords, queens with a hand to the cheek, mitred bishops with croziers, knights on small horses, shield-bearing warders as rooks, and runestones as pawns.
- A bone-and-slate board in a knotwork frame.

Switch to the classic set with **Set** in the top bar. The pieces are drawn in `tools/gen-norse.mjs`; run `npm run theme` after editing it (add `--preview out.html` for a preview sheet).

## Adding built-in openings

Edit `src/data/openings.js`. Each variation is a list of `[san, why]` pairs. Then run:

```
npm run validate          # every move legal, every move explained
npm run validate:engine   # also flags moves Stockfish thinks lose > 0.7 pawns (a few minutes)
```

## Layout

- `main.cjs`: Electron main process. Saves data and runs Stockfish (WASM, as a child process speaking UCI).
- `preload.cjs`: the bridge the UI uses.
- `src/`: the UI (chessground board, chess.js rules).
  - `views/`: home, opening overview, session (Learn/Drill), explore, library/editor.
  - `srs.js`: scheduling. `repertoire.js`: line index and book lookup. `engine.js`: engine client.
