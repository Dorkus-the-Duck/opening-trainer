# Opening Trainer

A chess app that teaches openings move by move, explains why each move is played, and uses spaced repetition so the lines stick. Stockfish 19 is built in.

## Get it

- **iPhone, iPad, Android or any browser:** open **https://dorkus-the-duck.github.io/opening-trainer/**. On iPhone/iPad, open it in Safari, tap Share → **Add to Home Screen**, and it runs full-screen like an app, even offline.
- **Windows:** download `Opening-Trainer-Setup-<version>.exe` from the [latest release](https://github.com/Dorkus-the-Duck/opening-trainer/releases/latest) and run it. Windows may say "Windows protected your PC" (the app isn't code-signed); click *More info → Run anyway*.

Both update themselves with new lines and fixes.

## Run it from source

```
npm install
npm start
```

`npm start` bundles the UI (esbuild) and opens the app. Requires Node 18+.

The **Opening Trainer** desktop shortcut runs `launch.vbs`, which does the same without a console window. Its icon is `assets/icon.ico`, generated by `npm run theme`.

## What's in it

**Repertoire (home).** Separate tabs for *Playing White* and *Playing Black*. Every line can be trained from either side (except the Fried Liver, which is a White-only weapon). Each line shows its status: New, Due, Next in Xd, or Mastered.

**Openings included** (about 10–12 moves deep, every move explained):

| Caro-Kann | Italian Game |
|---|---|
| Advance – Short System | Giuoco Pianissimo (c3 + d3) |
| Classical 4...Bf5 | Giuoco Piano c3 + d4 main line |
| Karpov 4...Nd7 with 5.Ng5 | Evans Gambit |
| Exchange | Two Knights – 4.Ng5 d5 5.exd5 Na5 |
| Panov–Botvinnik | Fried Liver Attack (White only) |
| Two Knights | Two Knights – modern 4.d3 |
| Fantasy 3.f3 | |

Each opening also has an **Overview & plans** page: pawn structures, plans for each side, and traps.

**Learn.** The trainer shows your move (arrow and explanation), you play it, and the opponent replies with its own explanation. If you try a different move, Stockfish compares your move with the book move from your side's point of view.

**Drill (spaced repetition).** You play the line from memory. *Hint* (key `H`) highlights the piece, then shows the move. At the end you grade yourself (Again / Hard / Good / Easy); a grade is suggested from your mistakes. Intervals follow an Anki/SM-2 style schedule: 10 minutes for Again, then 1d → 3d → growing. Trouble spots are remembered per line.

**Side lines for mistakes.** A wrong move stays on the board and opens a side line: Stockfish plays out the refutation, and the panel explains it (what the reply attacks or takes, material lost, the eval change, Blunder/Mistake/Inaccuracy/Playable). Step through it with ◀ ▶ or the arrow keys, then *Back to the line* to try again. In Drill the line's move stays hidden on the first mistake (just the piece is highlighted) and is shown on the second. Logic: `src/mistake.js`.

**Checkmates.** A beginner endgame trainer (♛ Checkmates in the top bar): ladder mate, king + queen, king + rook, "Don't stalemate!" traps, and promoting a pawn. Each has a guided lesson, then practice against Stockfish from random positions in four levels (mate-in-1 up to a full mate); a clean solve unlocks the next level. Stalemates and hanging pieces are caught with a take-back; in the pawn drill the engine also flags moves that throw the win away. After promoting you can carry on and mate with the new queen. Practiced topics join the normal Review queue (cards `mate:<topic>|w`, graded automatically). Lessons are in `src/data/mates.js`; practice positions in `content/mate-positions.json` come from `npm run mates:positions`; `npm run validate:mates` checks both.

**Explore & Study.**
- A free board with a move tree, including side variations (Promote / Delete). Navigate with ← → Home End; press F to flip.
- Stockfish analysis: top 3 lines plus an eval bar. Click a line to play it.
- **Book** tab: repertoire moves from the current position, with explanations, and whether the last move was book.
- **Notes** tab: write notes on any position. Notes are tied to the position, so they also appear during drills when you reach it.
- **Saved studies**: save and reopen whole move trees.
- Play against the engine from any position (Easy, Club, Strong, Full).
- Load / copy FEN or PGN.
- **Save line to repertoire…**: turns the moves on the board into your own Learn/Drill line.

**My Lines.** Edit or delete your custom lines. You can add them to Caro-Kann or Italian, or create a new opening. The data file holds all progress, notes, studies and custom lines (`%APPDATA%/opening-trainer/chess-trainer-data.json`); back it up by copying it.

**Feedback.** The ✉ Feedback button (and "Report a problem" during Learn/Drill) drafts an email to the address in `app.config.json`, with the app version, line and board position filled in.

**First-run tour.** A short guided tour runs the first time the app opens; the **?** button replays it.

## Piece sets and boards

Pick them under **🎨 Style** in the top bar.
- **Pieces:** Norse (Lewis chessmen: seated kings with swords, queens with a hand to the cheek, mitred bishops, knights on small horses, shield-warder rooks, runestone pawns), Classic, Minimal (flat geometric), and Shatranj (abstract medieval Islamic pieces).
- **Boards:** Bone & slate (with a knotwork frame), Brown, Walnut & maple, Tournament green, Blue ice, Marble, Black & white.

The art is generated in `tools/gen-norse.mjs` and `tools/gen-sets.mjs`; run `npm run theme` after editing them (`node tools/gen-sets.mjs --preview out.html` writes a preview sheet).

## Sharing and updates

- **Installer:** `npm run dist` builds `release/Opening Trainer Setup <version>.exe`. It isn't code-signed, so Windows shows "Windows protected your PC" the first time; click *More info → Run anyway*.
- **Line updates:** installed apps download `content/openings.json` from the GitHub repo in `app.config.json` at startup (and every 6 hours) and switch to it when its `version` is newer. Fixing or adding lines only needs a push; no reinstall. A pack can set `"minAppVersion"` if it needs a newer app.
- **App updates:** bump `version` in `package.json`, then `npm run release` (with a GitHub token in `GH_TOKEN`) publishes a GitHub Release. Installed apps download it in the background and offer to restart.
- **Web app (iPhone, iPad, Android, any browser):** https://dorkus-the-duck.github.io/opening-trainer/. Every push to `main` rebuilds and redeploys it (`.github/workflows/pages.yml`), so line fixes reach it the same way. On iPhone/iPad, open the link in Safari, tap Share → *Add to Home Screen*; it then runs full-screen and works offline. Progress is stored in that browser; *My Lines → Download backup* moves it between devices. Test locally with `npm run web` (http://localhost:8765).

## Layout

- `main.cjs`: Electron main process. Saves data, runs Stockfish (WASM, as a child process speaking UCI), checks for line and app updates, and serves proposals in dev.
- `preload.cjs`: the bridge the UI uses.
- `app.config.json`: feedback email and GitHub repo used for updates.
- `content/`: `openings.json` (the line pack) and `proposals/` (lines awaiting review).
- `src/`: the UI (chessground board, chess.js rules).
  - `views/`: home, opening overview, session (Learn/Drill), explore, library/editor, proposals, mates (Checkmates).
  - `srs.js`: scheduling. `repertoire.js`: line index and book lookup. `engine.js`: engine client. `content.js`: bundled vs downloaded line pack. `feedback.js`, `tour.js`.
- `src/web/`: the web build's stand-in for the preload bridge (localStorage, Stockfish lite in a Web Worker, service-worker updates). `web/`: its page, manifest and service worker. `build-web.mjs` builds it into `web-dist/`.
- `tools/`: art generators, icon maker, `content-io.cjs` (proposal merging).
